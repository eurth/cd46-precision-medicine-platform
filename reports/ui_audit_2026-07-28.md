## Classification

### A. Our regression (Phase 4 Expression Atlas)

- **Symptom:** `KeyError: ['cd46_mean', 'cd46_std']` when active target is FOLH1 (or any non-CD46 gene).
- **Cause:** Tab 1 charts were parameterized to `median_expr`, but Priority tab still hard-coded `cd46_mean` / `cd46_std`.
- **Fix:** use `{gene}_mean` / `{gene}_std` with fallbacks (patched in `1_cd46_expression_atlas.py`).

### B. Pre-existing hard crash

- **Survival Outcomes:** `3_survival_outcomes.py` contains **two (almost three) copies** of the page. Duplicate Streamlit `key=` → page unusable.
- **Fix later (or next hotfix):** delete duplicate block(s); keep one copy; unique keys.

### C. Pre-existing cosmetic / trust damage

- Patient Selection, Biomarker Panel (and any file with `ðŸ` / `â€` in source): broken icons and punctuation.
- **Fix later:** encoding repair pass across those files (no logic change).

### D. Not UI but worth tracking

- Non-CD46 targets still thin-slice only (no survival/HPA depth) — expected.
- Case-study pages still CD46-centric by design.
